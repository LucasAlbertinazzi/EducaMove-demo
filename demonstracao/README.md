# EducaMove Demo — experiência do estudante

- [Abrir a demonstração web](https://educamov.com.br/demonstracao/)
- [Baixar o APK EducaMove Demo](https://github.com/LucasAlbertinazzi/EducaMove-demo/releases/download/v1.0.0-demo-feed.20261011/EducaMove-Demo.apk)

Quatro abas: Início com feed municipal, Frequência, Reembolso e Perfil.
Perfil reúne a renovação anual e a segurança da sessão.

A prefeitura define o percentual anual do reembolso. O estudante informa o
valor pago à transportadora e o aplicativo calcula o valor a reembolsar.
Exemplo fictício de Brotas: R$ 400,00 × 50% = R$ 200,00.

## Acessos demonstrativos

- Brotas: demo@example.com / 123456 (50% ilustrativos).
- São Carlos: demo.saocarlos@example.com / 123456 (40% ilustrativos).

Notícias, dados e regras são fictícios; não há pagamentos, envio de documentos,
backend ou e-mail. Os registros são mantidos apenas durante a sessão.

O APK possui nome e identificador próprios: EducaMove Demo,
br.com.edumove.edumove_brotas_app.demo. Pode instalar ao lado do aplicativo
integrado. Distribuição interna para testes; no iPhone/iPad, use a web.

Esta pasta contém somente arquivos compilados. O código-fonte não é publicado.
